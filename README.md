# Tossed

Deploy-ready static PWA for Rogue Valley Cornhole.

## Included
- Play Riley with selectable skill
- 1v1
- Dime Bags (10 rounds, 1–2 players)
- Doubles with optional Riley fill or 1-vs-2 practice
- Current Throw and score entry at the top
- PPR, rounds, IN, ON, and OFF%
- Local autosave
- Supabase player/result sync
- Fullscreen toggle with Silk/iOS fallback guidance
- Installable PWA/service worker

## Deploy
Upload the entire folder contents to the root of the GitHub Pages branch. GitHub Pages must serve `index.html` from the same folder as `manifest.webmanifest` and `sw.js`.
